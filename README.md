# Aura Space — Workspace Management System

A complete management system that helps workspace administrators monitor analytics, manage clients, and track payments.

## 🚀 Overview
Aura Space provides an intuitive dashboard for tracking customer data, financial operations, and performance analytics.

## ✨ Features
- Client management module  
- Payment and invoice tracking  
- Data visualization using Chart.js  
- Admin dashboard with secure access  
- REST API integration

## 🧰 Tech Stack
- React.js  
- TypeScript  
- Tailwind CSS  
- Chart.js  
- REST APIs
